Code

Each version is one big hand-written HTML file, with no build step: - Production: fugio-site/gummy-fisherman-copy/index.html (~310 KB) + packages.js (question packages) - Test: fugio-site/gummy-fisherman/index.html - Phone: fugio-site/gummy-fisherman-mobile/play.html

Question packages

A package builder script (build-packages.js) turns Foxino gap-fill content (JSON) into packages.js:

node build-packages.js <content.json> <output>/packages.js

A dialogue with several gaps becomes one question per gap. Never edit packages.js by hand; rebuild it.
